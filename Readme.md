Сайт с нейросетью доступен по https://ru.amibka.site
Сайт хоститься на сервере в Москве где установлен Nginx, а Cloudflarare tunnel прокидывается API нейросети до сервера
Чтобы код полноценно работал нуженн локальный ии сервер типо Lm Studio или Ollama с моделью любой

Существует две версии кода для продакшана он на сервере, а этот код для локального ипользования вся разница только в файле .env
